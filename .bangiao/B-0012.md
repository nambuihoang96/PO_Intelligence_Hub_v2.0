# B-001.2 — Import UX handoff

## Root cause

- The import handler set loading before validating the Environment, leaving request state coupled to client validation and making submit feedback unclear.
- The save action had no in-flight guard or long-request status, while preview validation did not separately identify required fields.
- Structured JSON was only rejected after submission by the backend, and GEO was a free-text input.

## Changes

- Added immediate JSON syntax validation, explicit checks for Research question, GEO, Environment, and original report content. Structured JSON alone cannot be imported.
- Added a ref-based duplicate-submit guard. Loading now covers only the actual request, shows “Đang lưu báo cáo...”, and adds a slow-request note after eight seconds. Backend/network errors turn loading off; duplicate imports retain their report viewer route and notice.
- Replaced free-text GEO with a keyboard and mouse accessible searchable combobox. Common global/market options appear first, followed by local country options; custom GEO remains available through “Other / custom”. Submitted GEO remains a string.
- Made API errors more readable and added responsive dropdown/validation styling.
