## Delivered

- Home is now a Research Intake with question, GEO, OS, research type and research-period fields, a ChatGPT prompt builder/copy action, report paste/file import, preview/validation, and recent history.
- Prompt instructions enforce market-first analysis, source links, distinct OS/GEO/time scope, explicit gaps/confidence/PO next steps, and no unsupported downloads/revenue/growth inference. The app does not call AI or external APIs.
- Added report import/list/detail endpoints: `POST /api/v1/reports`, paginated `GET /api/v1/reports`, and `GET /api/v1/reports/{report_id}`.
- Report text is stored verbatim with question, GEO, OS, period, import time, `chatgpt_user_import` origin and SHA-256. Duplicate content returns the existing report. Imported reports remain `unverified`.
- Added history and a Markdown report viewer with headings/table of contents, common Markdown formatting and safe HTTP(S) links. Imported HTML remains text; links are not fetched automatically.
- Added one additive SQLite migration (`20261017_0004`) for `imported_research_reports`. Existing tables, Research Plans, Run Manifests, Projects, Runs, Evidence and Sources are unchanged.
