# PO Hub — Owner Release Check

Use your real report and original Sensor Tower export in the local PO Hub. The QA fixtures are examples only and are not market findings.

## A. Check one real ChatGPT report

1. Open **Home → Import ChatGPT report** and import one report you already use.
2. Open the saved report. Confirm the original report is still available and review its Findings and Evidence.
3. Connect the report to the appropriate existing research workspace, then attach a relevant finding to a PO decision if it supports one.
4. Save the assessment and next action. Refresh the page and reopen the decision.

Confirm that the report, finding, evidence, and decision remain available. If the report has no structured findings, it should still be saved as an unstructured report; do not treat headings as findings.

## B. Check the Sensor Tower export

You can inspect the original rows and select products. Before comparing growth, confirm from the export or Sensor Tower documentation:

- The actual GEO represented.
- What `Unified` means for platform coverage.
- The metric definition and measurement method.
- Exact start/end dates and whether each value is a snapshot, rolling window, or reporting interval.
- That both comparison periods use compatible definitions and coverage.

If the export cannot confirm a detail, leave it unknown and request a suitable export. Do not guess or type metadata just to enable a chart.
